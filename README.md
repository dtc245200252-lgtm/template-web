# Template Web Có Giao Diện Đẹp Mắt (Advanced Website Template)

Website template nâng cao với giao diện hiện đại, chuyên nghiệp sử dụng HTML5 & CSS3 (Flexbox & CSS Grid).

## 🚀 Các tính năng nổi bật

- **Header sống động**: Nền ảnh sắc nét kèm hiệu ứng làm mờ (`blur`) và lớp phủ tối màu tạo độ tương phản.
- **Fixed Navigation Bar**: Thanh menu cố định trên đầu trang khi cuộn (`position: fixed`) với hiệu ứng hover màu cam sang trọng.
- **Card Layout với CSS Grid**: Bố cục 3 cột dịch vụ cân đối, hiệu ứng phóng to (`scale 1.05`) khi rê chuột.
- **Footer chuyên nghiệp**: Bố cục 2 cột bằng Flexbox, hiển thị bản quyền và các liên kết mạng xã hội phân cấp bằng dấu chấm (`•`).
